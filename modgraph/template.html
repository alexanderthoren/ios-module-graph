            How to use

            1. Explore the graph — click a circle to drill in.
            2. Found something you want to extract? Hit 🎯 plan on it — the Plan tab shows the exact ordered path of folders to migrate first.
            3. Or open Plan for the global recommended order; click Migrate on a step to simulate extraction and watch what unlocks (orange).
            4. The Legend (bottom-right of the graph) is always visible.

            About

            Each folder with .swift files is a node. An edge A → B means a file in A references a type declared in B. References are resolved by USR from the compiler index store, so name collisions don't create phantom edges.
